# WaowoShop - Guide Utilisateur

## 🎯 Bienvenue sur WaowoShop

WaowoShop est une application mobile de e-commerce moderne et intuitive qui vous permet de :
- Parcourir un large catalogue de produits
- Rechercher des articles facilement
- Ajouter des produits à votre panier
- Passer des commandes en toute confiance
- Suivre l'historique de vos achats

## 🚀 Premiers Pas

### Installation

1. **Télécharger l'APK**
   - Récupérez le fichier `app-release.apk`
   
2. **Installer sur votre appareil Android**
   - Ouvrez le gestionnaire de fichiers
   - Naviguez jusqu'au fichier APK
   - Appuyez pour installer
   - Acceptez les permissions demandées

3. **Lancer l'application**
   - Trouvez l'icône "WaowoShop" sur votre écran d'accueil
   - Appuyez pour lancer

### Première Connexion

1. **Créer un compte** (optionnel)
   - Appuyez sur "Sign Up"
   - Remplissez votre nom complet
   - Entrez une adresse email valide
   - Créez un mot de passe sécurisé
   - Appuyez sur "Sign Up"

2. **Ou utilisez le compte de test**
   - Email : `test@example.com`
   - Mot de passe : `test123`
   - Appuyez sur "Login"

## 📱 Navigation Principale

L'application utilise une **barre de navigation inférieure** pour accéder aux sections principales :

### 1. **Accueil** (Home)
- Vue du catalogue principal
- Affichage des catégories en haut
- Grille de produits recommandés
- Barre de recherche pour trouver rapidement

### 2. **Catégories** (Categories)
- Filtrez les produits par type
- Disponible : Electronics, Computers, Tablets, Wearables, Storage, Furniture, Accessories

### 3. **Panier** (Cart)
- Voir tous les articles ajoutés
- Modifier les quantités
- Voir le total estimé
- Procéder au paiement

### 4. **Commandes** (Orders)
- Historique de toutes vos commandes
- Statut de chaque commande
- Détails des articles commandés
- Total payé

### 5. **Profil** (Profile)
- Informations de compte
- Statistiques (nombre de commandes, etc.)
- Options de profil
- Déconnexion

## 🛍️ Comment Acheter

### Étape 1 : Parcourir les Produits

```
Accueil → Voir tous les produits
         → Filtrer par catégorie
         → Rechercher un article spécifique
```

### Étape 2 : Ajouter au Panier

```
Sélectionner un produit
↓
Cliquer sur "Add" ou "Add to Cart"
↓
Confirmation affichée
```

### Étape 3 : Modifier le Panier

```
Aller à l'onglet Panier
↓
Modifier les quantités (+ ou -)
↓
Supprimer un article (icône corbeille)
```

### Étape 4 : Passer la Commande

```
Panier rempli
↓
Appuyer sur "Proceed to Checkout"
↓
Commande confirmée
↓
Voir la commande dans l'onglet Commandes
```

## 🔍 Recherche et Filtres

### Rechercher un Produit

1. Allez à l'**Accueil**
2. Utilisez la **barre de recherche** en haut
3. Tapez le nom du produit (ex: "iPhone", "Laptop")
4. Les résultats s'affichent automatiquement

### Filtrer par Catégorie

1. Allez à l'**Accueil** ou **Catégories**
2. Sélectionnez une catégorie parmi les chips
3. Les produits se filtrent automatiquement

## 💳 Paiement

WaowoShop utilise un système de **paiement simulé** pour les tests.

### Processus de Paiement

1. Allez à votre **Panier**
2. Vérifiez votre commande
3. Appuyez sur **"Proceed to Checkout"**
4. Commande confirmée instantanément
5. Consultez votre commande dans l'onglet **"Orders"**

### Statuts de Commande

| Statut | Signification |
|--------|---------------|
| **Pending** | En attente de traitement |
| **Processing** | Préparation en cours |
| **Shipped** | Expédié |
| **Delivered** | Livré |
| **Cancelled** | Annulée |

## 🐛 Dépannage

### Problème : "App not installed"

**Solutions** :
1. Assurez-vous que l'appareil a suffisamment d'espace (minimum 100 MB libre)
2. Vérifiez que vous installez depuis une source approuvée
3. Réessayez l'installation

### Problème : Les images ne s'affichent pas

**Solutions** :
1. Vérifiez votre connexion internet
2. Attendez quelques secondes pour le chargement
3. Redémarrez l'application

### Problème : Impossible de se connecter

**Solutions** :
1. Vérifiez votre email et mot de passe
2. Si c'est votre premier accès, créez un compte
3. Essayez le compte de test : `test@example.com` / `test123`

### Problème : Le panier ne se vide pas après paiement

**Réinitialisation** :
1. Fermez l'application complètement
2. Attendez 5 secondes
3. Rouvrez l'application

## 📞 Support

Si vous rencontrez des problèmes :

1. Redémarrez l'application
2. Videz le cache (Paramètres → Applis → WaowoShop → Vider le cache)
3. Réinstallez l'application si nécessaire
4. Consultez la FAQ
